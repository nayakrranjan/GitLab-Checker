GitLab Public Repository Risk Scanner Endpoints

← Back to Web Dashboard  |  Download OpenAPI Spec
POST /api/v1/scan Execute risk scan with JSON payload
Request Body (application/json)
{
  "target": "gitlab-org",
  "type": "AUTO",              // Optional: AUTO, USER, GROUP, PROJECT
  "token": "glpat-...",        // Optional: Private token for authenticated scan
  "baseUrl": "https://gitlab.com", // Optional: Custom instance
  "publicOnly": true          // Optional: Defaults to true
}
Response (200 OK)

Returns complete ScanResponse with metrics, scanned projects, and detected risks.

GET /api/v1/scan Execute risk scan with query parameters
Query Parameters
ParameterTypeRequiredDescription
targetstringYesGitLab username, group name, or project path
typestringNoAUTO, USER, GROUP, or PROJECT
tokenstringNoGitLab Personal Access Token for private repos
baseUrlstringNoCustom GitLab base instance URL
publicOnlybooleanNoFilter public repositories (default true)
GET /api/v1/scan/table Retrieve scan results formatted as ASCII CLI table

Returns text/plain containing the structured CLI table (Project Name | Issue | Severity) matching problem specifications.

GET /api/v1/scan/export/json Download complete scan report as JSON file

Returns downloadable scan-report-[target].json attachment.

GET /api/v1/scan/export/pdf Download formatted audit report as PDF document

Returns downloadable scan-report-[target].pdf attachment.

GET /health Service Health Check

Returns status string: "GitLab Risk Scanner is running".
